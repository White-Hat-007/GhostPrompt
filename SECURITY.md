# GhostPrompt Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within GhostPrompt, please report it responsibly:

1. **Email**: security@ghostprompt.ai
2. **Do NOT** open a public GitHub issue
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 24 hours
- **Initial Assessment**: Within 72 hours
- **Fix Development**: Within 7 days for critical, 30 days for others
- **Public Disclosure**: After fix is available and deployed

## Bug Bounty

We offer a bug bounty for critical security vulnerabilities.
Contact security@ghostprompt.ai for details.

## Scope

In scope:
- GhostPrompt API and backend
- Detection engine bypass techniques
- Authentication/authorization flaws
- Data exposure vulnerabilities

Out of scope:
- Social engineering attacks
- Denial of service attacks
- Issues in third-party dependencies (report upstream)
